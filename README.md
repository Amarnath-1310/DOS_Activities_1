# Descience_OpenSource_Activity_1

A small static web project containing a single HTML page, stylesheet, and image assets created for the **Descience Open Source Club**.  
This project serves as a simple front-end exercise to help beginners understand basic HTML and CSS structure.

---

## 🗂️ Project Structure

- `index.html` — The main landing page (HTML).
- `style.css` — Stylesheet defining layout and visual design.
- `pic/` — Folder containing image files used in the project.
- `README.md` — Project documentation (this file).
